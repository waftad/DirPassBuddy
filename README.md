# DirPassBuddy

A MIDI player Progressive Web App — play MIDI files from a local folder, queue
songs, and change playback speed. Runs on Windows (Chrome/Edge) and ChromeOS,
and installs as an offline-capable app.

The application lives in **[`NAC Church MIDI/`](NAC%20Church%20MIDI/)**. See that
folder's [README](NAC%20Church%20MIDI/README.md) for full details.

## Quickstart

```bash
cd "NAC Church MIDI"
npm install
npm run dev
```
